# Agent Engineering 课程术语表

本表只维护课程内的工作定义、首次引入和正式展开位置，不试图替代百科或产品文档。不同生态若使用同名异义，文章必须说明采用哪一种定义。

| Term | 课程工作定义 | 首次引入 | 正式展开 | 边界说明 |
|---|---|---:|---:|---|
| LLM / Model | 根据输入上下文生成输出的模型能力；本身不等于完整 Agent | 00 | 01 | 与 API、产品和 Runtime 分开 |
| AI Application | 把模型调用嵌入确定性软件流程的应用 | 00 | 01—04 | 可以没有 Agent Loop |
| Copilot | 以人类主导、AI 辅助为主要交互关系的产品形态 | 00 | 00 | 是产品交互模式，不保证统一内部架构 |
| Agent | 能围绕目标在状态和约束下循环决定、调用能力、观察结果并停止的执行系统 | 00 | 08 | 定义侧重工程行为，不等同人格化助手 |
| Agentic | 描述系统具有一定自主决策特征的程度性形容词 | 00 | 00 | 不作为严格架构类型 |
| Runtime | 承载一次或多次 Agent 执行的内核，包括 loop、state、tool execution 和 stop | 00 | 25 | 不自动包含全部治理能力 |
| Harness | 围绕 Agent Runtime 提供可复用横切工程能力的控制面抽象 | 00 | 24—27 | 课程抽象；不是已统一的行业标准名词 |
| Host | 装配 Runtime、Harness、Provider、配置与产品入口的宿主程序 | 00 | 25、29 | Host/Product 与执行内核分离 |
| Capability | Agent 可被授予和治理的一类能力契约 | 00 | 26 | 不等同某一个具体 Tool |
| Provider | 某类模型、工具或基础设施契约的可替换实现 | 00 | 04、31 | Provider 差异需要 adapter/seam 吸收 |
| Prompt | 提供给模型的任务合同、指令、示例和边界表达 | 00 | 02 | 不是全部 Context |
| Context | 某一步实际可见的输入集合及其选择、排序、压缩和来源 | 00 | 12—13 | 与长期存储分离 |
| Tool | 模型或 Runtime 可请求调用的外部动作契约 | 00 | 05—07 | Tool schema 不等于安全执行 |
| Skill | 可按需加载的领域方法、规则与配套资源 | 00 | 17 | 不只是更长的 Prompt，也不必等同插件 |
| Workflow | 由确定性步骤、状态与明确决策点组成的任务骨架 | 00 | 10 | Agent 可以嵌入 Workflow，二者不互斥 |
| Working Memory | 当前任务中可更新的短期工作状态 | 00 | 14 | 不等同完整会话日志 |
| Session | 一次可追踪、恢复或回放的交互与执行边界 | 00 | 15、34 | 具体生命周期由 Runtime 定义 |
| Long-term Memory | 跨 Session 保留、检索和更新的信息 | 00 | 15 | 需要作用域、可信度和遗忘策略 |
| Project Memory | 绑定项目范围的事实、决策和经验记忆 | 00 | 15 | 不能自动当作当前事实 |
| Knowledge Base | 经过组织、可检索并带来源边界的知识集合 | 00 | 16 | 与未经治理的聊天历史不同 |
| RAG | 在生成前检索、过滤、重排、注入并引用外部知识的管线 | 00 | 16 | 检索到不代表答案正确 |
| Evidence | 支撑某个可审计主张的来源、观测、实验或明确设计提案 | 00 | 18 | 必须声明证明范围与不证明范围 |
| Trace | 跨 step、tool、provider 和状态变化的结构化执行记录 | 00 | 21 | 日志是载体之一，不自动等于完整 Trace |
| Replay | 基于已记录事件重建状态或重演执行的能力 | 00 | 21、34 | 重建与重新调用外部副作用需区分 |
| Eval | 用固定任务、判据和数据度量系统行为的评估过程 | 00 | 22 | 单次 Demo 不是回归评估 |
