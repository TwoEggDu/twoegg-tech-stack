The first PowerShell-only independent audit helper attempted to cast byte arrays to ReadOnlySpan<byte>. PowerShell does not support byref-like ReadOnlySpan values, so the helper emitted InvalidArgument errors. Its generated PASS field is invalid and the preserved file is explicitly named independent-audit-attempt-01.invalid.json. This helper failure did not affect the C# Spec runner compare result. The corrected helper uses StructuralEqualityComparer on byte arrays.
