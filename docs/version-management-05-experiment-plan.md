## 范围与结构

文章类型：工程方法，采用“只交付 A 的问题 → 工作目录/候选/历史/接收副本 → 命令验证 → 工程边界”。

Git 主实验使用 Python 3.11+ 标准库、Git、一个本地裸仓库、开发仓库和干净接收仓库。Unity 版本不适用：不启动引擎、不使用项目资产；本轮验证小型 Python 教学程序的行为，不能据此声称游戏可用。SVN/P4 只核对文件分组与内容选择的官方语义，引用既有实验，不新增对应端到端验证。

固定任务：A 把伤害由 100 改为从新文件 `damage.json` 读取 80；B 在同一个 `skill.py` 中启用未完成的蓄力，另改备注与合成二进制文件、删除旧文件并保留未跟踪草稿。候选只允许包含 A 和它的 JSON 依赖。A、B 的文本修改在不同函数，刻意排除语义耦合；二进制仅验证整文件保留，不演示片段拆分。

## 验证块 1：缺失依赖能在干净候选中暴露

**结论**：开发目录能运行，不足以说明候选包含全部输入。

- 最小场景：基线已提交且推送；开发目录同时有 A+B 和新 JSON。先只选择 A 的脚本修改，导出暂存树到全新目录运行，再把 JSON 加入候选重试。
- 控制变量：两次候选保持脚本 blob 相同，唯一变化为 JSON 文件；无网络、外部包、环境搜索路径和引擎缓存。通过绝对脚本路径和脚本自身目录读取 JSON，禁止向候选手动补文件。
- 观测指标：开发目录运行退出 0；缺依赖候选非零且报缺少 JSON；完整候选退出 0、输出 `damage=80` 与 `charge=false`。记录候选树、文件清单、命令退出码和输出。
- 工具与位置：`git diff --cached`、`git write-tree`、`git checkout-index --prefix`；在每个新目录运行 `python -B skill.py`。
- 预期：补齐依赖后只改变候选完整性，原开发目录保持不变。
- 异常排查：检查候选是否误读开发目录、是否导出了磁盘而非 index、新依赖是否真的进入 index；不以退出码以外的主观描述代替结果。

## 验证块 2：同文件选择 A，同时保留 B

**结论**：文件范围与内容范围分开核对，能构造只含 A 的候选并保留开发目录全部原始内容。

- 最小场景：`skill.py` 同时有 A、B；命令教学说明 `git add -p`，自动复跑用明确审阅的 A 补丁 `git apply --cached`，不伪称执行了交互选择。
- 控制变量：固定基线及 A 补丁；补丁只改伤害函数；候选不得包含备注、二进制、删除动作和未跟踪草稿。脚本只在新实验仓库修改 index。
- 观测指标：index 的脚本与 A 目标逐字节一致；磁盘仍为 A+B；候选文件清单恰好为 `skill.py` 与 `damage.json`；开发目录所有文件的相对路径与 SHA256（含未跟踪、合成二进制、缺失路径）在选择、拒绝、提交、推送前后保持一致。
- 工具与位置：`git diff` / `git diff --cached`、`git show :skill.py`、Python SHA256；最终接收副本验证行为并检查干净状态。
- 预期：接收副本是 80 / false，开发目录保持 80 / true，其他 B 修改完整保留。
- 异常排查：核对是否整文件 add、补丁误含 B、检查遗漏未跟踪文件或删除；若修改相互依赖，应调整任务边界而非强拆。

## 验证块 3：明确拒绝与结果不明采用不同核对

**结论**：报错不等于所有步骤均未发生，重试之前要定位实际完成到哪一层。

- 最小场景：仅给新开发仓库安装本实验 `pre-commit` hook，确定性拒绝一次本地 commit；检查后禁用自己的 hook，再成功 commit。随后 push 到本地裸仓库，由教学包装器丢弃对调用方的回执，模拟客户端结果 unknown。
- 控制变量：拒绝不触及用户仓库 hook；回执丢弃只是教学模拟，不称为真实网络中断或服务故障；控制端保留真实 push 退出码用于审计，调用方判定仅使用重新查询的远端 ref。
- 观测指标：拒绝后 HEAD、index tree、磁盘清单不变，远端仍为基线；成功 commit 的父提交为基线、tree 等于已验收候选；unknown 后 `git ls-remote` 查询到精确提交 SHA，历史只增加一次记录，因此无需再 push；接收方明确 checkout 此 SHA 后运行通过且无 B。
- 工具与位置：`git rev-parse`、`git write-tree`、`git ls-remote`、`git rev-list`；新接收目录的行为输出、状态与文件散列。
- 异常排查：区分 hook 未执行、commit 已创建但 push 未执行、远端查询失败及 SHA 不符。查询失败保持 unknown；本实验不自动 reset、清理或强推。
