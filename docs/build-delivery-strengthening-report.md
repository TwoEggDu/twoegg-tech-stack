## 案例材料与公开边界

当前可确认的工作线来自作者陈述：依赖提交工具帮助减少资源依赖遗漏；本地 Unity 工具定位具体资源节点的 Missing；导表处理 `xlsx → bin`，反馈路径与配置依赖问题；机器人检查提交并将构建后的包下载入口送给 QA。

作者提供的通知样例补充了这些信息：

- 构建通知包含构建身份、源码版本、参数摘要、下载、预览二维码、有效期和详情入口。
