# 正式首页：交付地图

采用已选定的 B 结构与 C 配色，替换正式首页模板。预览目录保留为设计对照；正式构建不挂载或引用它。

## 页面与维护位置

- `/`：交付地图首页。入口为 `layouts/index.html`，内容编排在 `layouts/partials/reading/home.html`。
- `/reading/performance/`：按问题选择系列的性能主题导读。
- `/reading/startup-loading/`：启动与加载精选阅读顺序。
- `data/reading_paths.yaml`：正式页面共用的文章引用与导读。以后修改正式入口，在这里维护；`previews/reading-experience/` 中的旧数据作为设计记录保留。
- `layouts/partials/reading/document.html`：页框架、SEO 元信息、导航、搜索与页脚。
- `static/css/reading.css`、`delivery-home.css`：仅由首页和导读页加载，不进入既有文章模板。

两个导读页采用独立地址，不替换原有 `/performance/` 完整栏目，也不复制或迁移文章正文。它们不进入文章列表、搜索索引或 RSS。首页继续生成原有 RSS 和 JSON 输出。

正式页面去掉预览提示、版本切换与 noindex，保留 canonical、Open Graph 和搜索。保留地图、六组协作、六个主题和三篇实践的内容入口。

后续调整：主题中的“渲染与画面”改为“服务端框架”，接入 ET 前置桥接与框架源码解析。页首导航与首页主题列表共用 `reading_paths.yaml`，统一按“工程与交付 → 战斗与玩法 → 客户端框架 → 引擎研发 → 服务端框架 → 性能优化”排列；点击站点名称返回首页。手机导航自动换行，性能导读页显示所属导航状态。

## 作者与文章优先

首页先用第一人称说明客户端背景与写作范围，紧接着推荐《游戏生产管线总览》，说明推荐原因。三篇个人实践提前到地图之前；地图作为后续阅读入口，六组协作改为朴素的两列文章索引，去掉对称底色。主题顺序继续以交付为先。没有改写文章正文或新增项目经历。

文章、系列与导航链接常态显示蓝色下划线。地图四个目标使用原生链接整块点击，标明“进入阅读”，支持键盘焦点与 Enter 跳转。
