### 5. 推荐二级标题结构

```text
1. 检查报错以后，问题为什么还会停在那里 — 职责：用已有工具链解释定位、候选修正、提交与复检之间的交接需求；未统计的等待不写成事实数字。
2. 一次 Missing 处理究竟交接什么 — 职责：定义问题位置、输入版本、修正范围与复检结果四类信息，不展开全部数据结构。
3. 哪些步骤用固定流程就能完成 — 职责：提出普通漏交的无模型处理基线，明确依据工具回执推进。
4. 什么情况下仍需要进一步判断 — 职责：用明确标注的本地正常／检查机异常示例，区分缺事实、缺意图与可规则化调查。
5. 接下来的研究怎样回答是否值得用 Agent — 职责：给出待验证问题、初步职责表和后续阅读顺序，允许结论是无需模型。
```
