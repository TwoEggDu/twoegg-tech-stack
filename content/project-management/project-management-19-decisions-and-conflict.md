一位同事主张集中完成，另一位坚持分批推进。讨论了半小时，双方把理由又说了一遍，主持者最后写下：“原则上同意，大家再协调一下。”第二天，两个人仍按各自理解安排工作。

这种讨论没有把分歧转化为决定。问题可能不在表达能力，而在于大家始终没有说明：究竟要选什么、哪些条件不能突破、谁能作出取舍，以及决定之后由谁承担什么行动。

[PM-18]({{< relref "project-management/project-management-18-meetings.md" >}})讨论怎样组织共同时间；本篇处理其中最容易卡住的一步：**当意见不同且信息不完整时，怎样形成一个有依据、可执行、允许复查的选择。** 方法也可以用于书面讨论，不要求所有决定都开会。

## 一、先确认大家在争什么

“你不同意我的方案”只是表象。实际分歧可能发生在不同层面，处理入口也不同。下面的分类是本文用于整理讨论的工作框架，几类分歧可以同时存在。

| 分歧所在 | 需要澄清的问题 | 合适的下一步 |
| --- | --- | --- |
| 事实 | 我们看到的是同一版本、时段和范围吗？ | 对齐记录，检查来源；不能用投票决定哪条事实为真 |
| 利益与目标 | 各自想保护什么，又要承担什么损失？ | 让双方说明关切，寻找可调整条件；共同目标不意味着成本分配已经公平 |
| 资源与权限 | 两项工作是否在使用同一段时间、同一笔预算或同一个人？ | 核对承诺和可用性，交给有分配权的人取舍；协调者不能凭会议记录征用资源 |
| 判断 | 对同一组信息，为什么预测或风险偏好不同？ | 比较假设、后果和可逆性，补关键证据，再由约定的决定者判断 |

例如，“这个安排肯定来不及”可能是在说工时记录不对，也可能是在说自己的另一项承诺不能取消。前者需要核实，后者需要协调取舍。只劝对方“积极一点”，两种问题都没有解决。

Berkun 第11章讨论冲突时，强调先寻找共同点、理解利益，再讨论解决办法。[3] 可以把“我只接受分批”改问成：“分批主要是在保护日常服务、降低返工，还是解决人员不同时到场的问题？”应当由对方补充并确认，不能替其编出动机。

如果共同利益有限，就如实记录还有什么无法兼顾。方法不能保证每次都得到双赢结果。涉及持续羞辱、威胁或不公平对待时，也不能把行为问题淡化成方案分歧；需要按实际组织的申诉、管理或人事程序处理。

## 二、讨论开始前，把决定的边界写清楚

格鲁夫第5章区分自由讨论、清楚决策和支持执行，并提出在决策前明确内容、时限、参与者和最终权限。[1] 对日常工作，可以先补全下面这句话：

> 在【什么时点之前】，为了【什么结果】，需要在【哪些范围内】作出选择；由【谁按什么授权】决定，先征求【谁】的意见，涉及【什么条件】时另请【谁】确认，最后通知【谁】。

决策时限要连到后续工作：再不决定，会影响哪次排班、采购或交付？“今天必须定”如果没有实际原因，只会把尚可核实的事项变成仓促判断。

这里有三个不同动作：

- **征求意见**：获取知识、影响和异议。被咨询不表示拥有批准权，也不表示其意见可以被随意忽略。
- **形成共识**：相关人对选择有共同理解，并达到事先约定的支持程度。共识采用什么标准，需要提前说明，不能临时把沉默解释为同意。
- **作出决定**：有权者在范围内选择方案并说明理由。某些事项需要共同批准或满足特定程序，不能因为设置了一个牵头人就取消这些要求。

主持者、最资深的人、最懂细节的人和最终决定者可以是不同的人。Grove 对知识与职位的讨论、Berkun 对正式权限和影响力的区分，都提醒我们把信息带进决定；它们不意味着专业能力会自动产生预算或人事审批权。[1][4]

如果权限不清，先输出建议和待确认事项，连接[PM-02 的职责与决策约定]({{< relref "project-management/project-management-02-roles-responsibility-authority.md" >}})。越急，越需要知道谁可以作哪些临时决定、哪些条件仍不能豁免。

## 三、把立场变成可以比较的选项

下面是一段**独立的虚构教学情境**，不表示前面培训案例已经执行，也不是作者的真实管理经历。

一个部门准备整理公用资料柜，更新纸质目录和位置标签。目标是在约定完成日前，让目录中的位置与实物一致；范围只包括目录和位置，不更改资料内容、不丢弃资料。正常查阅服务需要维持，新增支出未经批准。

教学设定中，资料负责人已经确认两套可选排班：一次连续的非服务时段，或若干次较短的非服务时段。两套安排都包含执行、逐项核对和恢复服务的时间；选择其中一套后释放另一套。现有材料足够，不需要新增采购。这些是为了练习给定的条件，不是现实中的工时测量或资源承诺；实际采用时必须重新核实。

组织者倾向集中完成，值班同事倾向分批。经双方补充后，前者主要担心新旧目录长期并存，后者主要担心一次整理未完成会影响恢复查阅。现在可以把立场展开：

| 选择 | 怎样满足目标 | 主要代价与风险 | 需要确认或保留的条件 |
| --- | --- | --- | --- |
| A：集中整理后统一换用新目录 | 在连续窗口内完成移动、目录更新和逐项核对，再恢复查阅 | 新旧混用期较短；工作集中，单次延误会挤压恢复时间 | 连续窗口及人员仍可用；保留旧目录、位置对应记录和恢复时间 |
| B：分区整理，每次完成一区后开放 | 每区移动后同步改目录并核对，保留清楚的区域状态 | 单次受影响范围较小；多次交接，需要持续维护哪些区域已更新 | 短窗口及人员仍可用；指定过渡目录维护者，每次开放前核对 |
| C：暂时维持原样 | 查阅方式暂时不变 | 不占整理窗口，但不能按原约定完成更新 | 如要采用，须由有权者重新决定期限或目标，不能当成按原计划完成 |

A 和 B 在给定条件下是可行备选，C 提醒我们“不做”也有代价。若资源尚未确认，应将 A、B 标成候选方案，而不是为了凑比较表，直接写成可执行。

比较时先看**不能突破的条件**，再看偏好。资料不能丢失、服务开放时目录必须对应实物、不能产生未经批准的支出，是本例的边界。少一些交接、一次受影响范围小、组织工作更省力，则是需要权衡的偏好。不能靠某个“综合得分很高”，抵消一项不满足的必要条件。

Berkun 第8章建议比较选项的利弊，检查“怎么知道”，也提醒数据无法替人作决定。[2] 这张表因此没有给 A 打 8.7 分、给 B 打 8.5 分：没有共同定义和来源的分数，会把判断伪装成测量。确实需要加权评分时，也要公开标准、权重和证据，再检查调整权重是否会改变结论。

## 四、只补足以改变选择的信息

有一张表之后，还要问：**我们在依赖哪个尚未确认的假设？它如果不成立，会不会改变选择？**

本例对 A 的关键担忧是连续窗口中的恢复能力。可以在实际移动前核对资料清单与位置对应关系，检查能否在预留时间内停止整理、回到可查阅状态。谁负责检查、检查占用多少时间，都要放入已确认安排；需要额外试做时另行确认投入。本文没有执行过这项检查，也不预设它一定通过。

如果对应关系缺失，所谓“恢复原样”就可能只是愿望。此时先补记录，或重新评估 B，不能用负责人有信心代替恢复依据。即使位置能够恢复，已经花掉的时间和标签材料也回不来；可逆只说明某种状态可以恢复，不代表没有代价。

决定投入多少调查，要看决策影响、误判代价和剩余时间。[2] 对影响小、容易恢复、处于授权内的事项，可以设置有限试行和检查点；对外部承诺大、难以恢复或涉及必要审批的事项，需要先取得相应证据与授权。试行本身也占资源，并不是绕过审批的理由。

到决策时限仍有未知项，要说清它是什么：必要条件没确认，就不能启动依赖它的动作；属于可接受的不确定性，则由有权者明确接受哪种风险、观察什么信号、由谁响应。延期、缩小范围或放弃，也可能是需要提交的选项。

## 五、写下一页决策记录，让异议有去处

接着上述虚构情境，假定资料负责人拥有本次目录整理方式和已确认排班的决定权；人员所属负责人已分别确认两套备选安排。讨论后，资料负责人倾向 A，理由是本次优先缩短新旧目录并存的时间，同时保留值班同事对恢复能力的担忧。

这不是宣布 A 已经完成，也不是给 A 无条件放行。下面的记录将“选择方式”和“具备启动条件”分开。实际使用时，要把角色填成具体姓名，把相对时点填成日期，并附上对应证据。

| 字段 | 本例记录内容 |
| --- | --- |
| 待决定的问题与期限 | 在排班锁定前选择资料柜整理方式，完成期限及服务要求保持原约定 |
| 选项与依据 | 比较 A 集中、B 分区和 C 暂不整理；依据为确认过的排班、整理清单、现有材料及双方关切。真实应用须附可访问的记录版本 |
| 决定者及权限 | 资料负责人选择本次整理方式；人员承诺按已确认安排，新增支出、改期或影响服务另行审批 |
| 选择及代价 | 选择 A，并接受单次工作集中带来的恢复压力；优先减少新旧目录并存。未选择 B，仍保留其缩小单次影响范围的优势作为备选依据 |
| 启动条件与待办 | 组织者在移动前检查清单、位置对应记录和恢复安排；资料负责人确认检查结果满足服务要求后才允许移动。未通过则保持可查阅状态，提交修订建议 |
| 保留的异议 | 值班同事担忧单次延误。记录其理由和影响，由恢复安排回应；不把未赞同写成同意，也不要求撤回异议 |
| 执行与接收 | 组织者按获准安排牵头整理，值班同事核对目录与实物；资料负责人依据逐项核对记录确认能否恢复查阅。具体任务须由对应人员确认 |
| 通知 | 组织者把最终安排、过渡期间的查阅入口和恢复条件通知使用者；通知记录不代替执行和验收记录 |
| 复查触发与处理 | 窗口或人员变化、清单出现遗漏、整理进度侵占预留恢复时间时，组织者停止扩大移动范围，通知资料负责人；按已确认恢复安排保持或恢复可查阅状态，重新评估剩余工作 |

“预留恢复时间”在真实计划里必须有明确边界和依据，不能只留这几个字。到边界后发现 B 已经错过所需窗口，也不能自动切换 B；要重新确认人员、顺序和日期，必要时进入[PM-09 的变更过程]({{< relref "project-management/project-management-09-change-control.md" >}})。

这份记录让双方知道为何选择 A，也让反对意见影响了执行条件。格鲁夫把支持执行与完全赞同区分开来。[1] 在这里，支持执行意味着：对权限内、符合要求的决定，按确认的分工行动，及时报告异常；不意味着承认自己的预测错误，更不意味着隐瞒新证据、接受越权安排或取消正常申诉渠道。

如果负责人最后选择 B，同样要写明为什么愿意承担过渡目录和多次交接的成本。一个有效的决策过程应能解释另一种选择何时更合适，而不是让记录只为既定答案辩护。

## 六、决定之后，分别检查执行与结果

决定明确后，下一次检查不应只是问“大家有没有照做”。至少分开看：

1. **条件是否仍成立。** 排班、权限、资料清单和恢复安排有没有变化；有变化及时更新预测，不能沿用旧批准掩盖新问题。
2. **行动是否完成。** 移动、目录更新、逐项核对和通知是否按当前方案完成；完成状态需要相应记录。
3. **结果是否达到。** 恢复查阅后，目录与实物是否一致，是否出现找不到资料的情况；发现偏差后由谁修正、是否需要重新决定。

本例没有实际执行数据，因此只能说明怎样作决定和检查，不能证明集中整理比分批更有效。即使之后结果不好，也应先区分当时已知信息、后来变化和执行偏差；结果好也不能反过来证明当时忽略关键证据是正确的。

## 七、练习：改写一条模糊结论

下面仍是虚构练习：“多数人同意先集中整理，反对者会后配合，下周看看情况。”

把它改成可以执行的记录，至少回答四个问题：

- 多数人的支持是否满足本事项的决策程序？实际有权者是谁？
- 集中整理依赖哪些必要条件？哪些已经确认，哪些仍然未知？
- 反对者具体担忧什么，怎样核实并进入保护措施或复查条件？
- 谁在什么时点检查什么，出现哪种信号时停止、恢复或提交新决定？

题目没有给出的审批、日期、人员投入和恢复证据，应标成待确认。不要为让表格完整而补成已同意。完成后检查：一个没有参加讨论的人，能否据此找到当前选择、理由、行动入口和重新讨论的条件。能够找到这些信息，才算把争论接到了工作上。

## 来源与延伸阅读

1. Andrew S. Grove，《格鲁夫给经理人的第一课：畅销版》，中信出版社，2017，ISBN 9787508678092，第5章“不挥舞权杖的决策”。核对自由讨论、清楚决策、执行支持及决策前的六个问题；不把职位、资历或专业知识直接当成某事项的审批权限。
2. Scott Berkun，《项目管理之美》，机械工业出版社，2009，ISBN 9787111259527，第8章“如何制定好的决策”，重点为衡量决策、选项利弊、假设检查和信息的局限。本文未沿用原书的经验效果数字，也不把评分精细程度当成判断准确性。
3. 同书第11章“事情出错时该做什么”，重点为“冲突解决和谈判”“每个人都应该知道决策者是谁”。用于理解共同点、利益、选项和决策权限；本文不主张所有分歧必有双赢解，也不把紧急程度当成无限授权。
4. 同书第16章“政治与权力”，用于核对正式权限、知识与其他影响力的区别，以及资源和组织目标对选择的限制。

分歧分类、资料柜情境、选项表、决策记录和练习均为本文教学整理，未转录原书图表，不包含真实团队采用或效果数据。
